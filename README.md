# siKRAS + 5-FU CRC Bulk RNA-seq Analysis

Bulk RNA-sequencing analysis pipeline for investigating transcriptomic changes
induced by KRAS silencing (siKRAS) in colorectal cancer (CRC), and its
mechanistic link to 5-fluorouracil (5-FU) sensitisation.

**Core comparison:** siKRAS vs siScr (scramble control) in HCT116 cells.

---

## Overview

This repository contains a fully reproducible, end-to-end RNA-seq analysis
workflow:

1. Quality control (FastQC)
2. Alignment (STAR)
3. Differential expression (DESeq2 + lfcShrink)
4. Visualisation (MA / volcano / PCA)
5. Enrichment (GSEA + Enrichr)
6. TCGA survival validation (TPM / Kaplan-Meier / Cox)
7. KRAS allele-specific analysis
8. 5-FU mechanistic analyses (DNA repair sub-pathways, 5-FU response/resistance)

The workflow is organised as a series of Jupyter notebooks (one per step) that
call modular Python scripts in `scripts/`.

## Requirements

### Software

| Tool | Version | Purpose |
|------|---------|---------|
| Python | 3.10 | Runtime |
| STAR | 2.7.11b | RNA-seq alignment |
| FastQC | 0.12.1 | Quality control |
| samtools | 1.21 | BAM processing |

### Environment setup

```bash
conda env create -f environment.yml
conda activate sikras_rnaseq
```

### Reference genome

A STAR index for GRCh38.p14 (NCBI RefSeq annotation) is required. Either:

```bash
# Option 1: build your own index (requires genome FASTA + GTF)
STAR --runMode genomeGenerate \
     --genomeDir /path/to/STAR_index \
     --genomeFastaFiles /path/to/GRCh38.p14.fa \
     --sjdbGTFfile /path/to/annotation.gtf \
     --runThreadN 30

# Option 2: download a pre-built index
```

Also download the GENCODE v47 GTF (for TCGA TPM gene lengths):

```bash
bash scripts/download/download_gencode.sh
```

### Gene set libraries (offline enrichment)

The Reactome and LINCS L1000 gene set libraries used by the 5-FU mechanistic
analyses (notebook `10`) are cached as local GMT files in `Data/gene_sets/`
and are tracked in this repository, so those analyses run fully offline.

## Input data

Raw FASTQ files should be organised as follows (change `raw_data_dir` in
`config.yaml` to point to your data):

```
raw_data_dir/
├── Sample_1/
│   ├── Sample_1_1.fq.gz
│   └── Sample_1_2.fq.gz
├── Sample_2/
│   └── ...
```

The samplesheet is auto-generated by notebook `00`. Edit the `group` column
before running differential expression.

## Workflow

Run the notebooks in order:

| Notebook | Step | Output |
|----------|------|--------|
| `00_setup_and_samplesheet.ipynb` | samplesheet | `Data/samplesheet.csv` |
| `01_fastqc.ipynb` | QC | `Data/fastqc/` |
| `02_star_alignment.ipynb` | alignment | `Data/AlignBAM/` |
| `03_assemble_counts.ipynb` | count matrix | `Data/count_matrix_raw.tsv` |
| `04_preprocess.ipynb` | preprocess | `Data/count_matrix_processed.tsv` |
| `05_deseq_lfcshrink.ipynb` | DE | `Data/tables/`, `Figures/05_deseq/dispersion_plot.png` |
| `06_visualization.ipynb` | figures | `Figures/` |
| `07_enrichment.ipynb` | GSEA/Enrichr | `Data/tables/`, `Figures/07_enrichment/` |
| `08_tcga_validation.ipynb` | TCGA | `Data/tables/`, `Figures/` |
| `09_kras_allele.ipynb` | allele | `Data/kras_allele_counts.tsv`, `Figures/09_kras_allele/allele_counts.png` |
| `10_5FU_mechanism.ipynb` | 5-FU | `Data/tables/`, `Figures/10_5FU_mechanism/` |

## Key analysis parameters

| Parameter | Value |
|-----------|-------|
| DESeq2 thresholds | baseMean ≥ 10, padj < 0.05, \|log2FC\| > 0.5 |
| lfcShrink | apeglm |
| GSEA ranking | DESeq2 Wald statistic |
| GSEA permutations | 1000 |
| TCGA normalization | GENCODE v47 → TPM → log2(TPM+1) |
| KM split | median + log-rank test |
| Cox covariates | age, gender, stage |

## Data availability

Raw and processed sequencing data will be deposited in the NCBI GEO. TCGA and
GEO public datasets are downloaded on-the-fly by the scripts in
`scripts/download/`.
